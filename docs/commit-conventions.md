# Convención de commits
- `feat: implement login module`
- `fix: correct affinity calculation`
- `docs: update architecture document`
- `refactor: improve recommendation service`
- `test: add unit tests for profile module`
- `chore: update pom dependencies`

# Pull Requests
Feature branch → Pull Request → Code Review → Approval → Merge. No se hace commit directo a `main` ni a `develop`.
