# PathMind MVP

Plataforma web de orientación vocacional para estudiantes de grados 10° y 11° de instituciones educativas oficiales de Santiago de Cali. Usa el modelo RIASEC de Holland y un motor de recomendación explicable basado en reglas ponderadas.

## Módulos
1. Usuarios y Seguridad
2. Perfil Vocacional
3. Motor de Recomendación Explicable
4. Catálogo Académico

## Stack
Java 21 · Spring Boot 3 · PostgreSQL 16 · Thymeleaf + Bootstrap 5 · Maven · Docker

## Estructura
`backend/` código Spring Boot · `database/` scripts SQL · `docs/` documentación · `diagrams/` UML y C4 · `jira/` exportaciones del tablero · `ui-mockups/` diseños · `docker/` contenedores

## Flujo de trabajo
GitFlow: `main`, `develop`, `feature/*`, `release/*`, `hotfix/*`. Todo cambio entra por Pull Request.
Commits: `feat:`, `fix:`, `docs:`, `refactor:`, `test:`, `chore:`.
